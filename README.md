# Sales_Insights_Dashboard.pbix-with-3-interactive-pages-.
Interactive Power BI sales dashboard built on a 6-table data model (Orders, Customers, Products, Sellers, State, City). Features KPI cards, yearly and monthly trend lines, pie/donut/bar/treemap charts, synced slicers and 3 pages: Executive Overview, Product &amp; Seller, Customers &amp; Geography. Built for client-ready insights.
